Problem statement

Design a circuit that converts a 3-bit binary input into a proportional analog output voltage. Each input bit contributes a different weight, with D2 contributing the most and D0 the least.

3. Theory: binary-weighted DAC

In a binary-weighted DAC, each digital input controls a voltage source or switch. The inputs are connected through resistors whose values scale by powers of two. Since current through a resistor is proportional to voltage and inversely proportional to resistance, the MSB contributes the largest current.

The op-amp's inverting input is held near virtual ground under ideal negative feedback. Input currents add at the summing node and flow through the feedback resistor, producing a negative output voltage.

Key terms

  • MSB: Most significant bit, with the largest numerical weight.
  • LSB: Least significant bit, with the smallest numerical weight.
  • Resolution: The output change caused by a one-count increase in the digital input.
  • Full-scale output: The output magnitude at the largest digital code, 111.
  • Virtual ground: A summing node held close to 0 V by negative feedback, although it is not directly connected to ground.

5. Working principle

  1. Each digital input is either LOW (0 V) or HIGH (5 V).
  2. A HIGH input sends current through its associated resistor toward the inverting summing node.
  3. The three currents add together at the node.
  4. Negative feedback through R4 forces the op-amp output to a voltage that balances the summed current.
  5. Because the input enters the inverting terminal, the output is negative for nonzero positive input codes.
Remember: Halving the input resistor doubles its current contribution. Therefore 10 kΩ contributes twice as much as 20 kΩ, and four times as much as 40 kΩ.

Operating assumptions

  • Ideal op-amp: input current approximately zero and input terminals held at nearly equal voltage under negative feedback.
  • Logic sources are ideal 0 V and 5 V levels.
  • Resistors have exact stated values.
  • The op-amp has sufficient output swing and is not saturated.

6. Equation derivation and theoretical results

Let D2, D1 and D0 be binary variables, each equal to 0 or 1. Their physical voltages are 5D2, 5D1 and 5D0 volts.

IΣ = (5D2 / 10 kΩ) + (5D1 / 20 kΩ) + (5D0 / 40 kΩ)

For an inverting summing amplifier, Vout = −Rf × IΣ. Here Rf = R4 = 5 kΩ.

Vout = −5 kΩ [(5D2 / 10 kΩ) + (5D1 / 20 kΩ) + (5D0 / 40 kΩ)]
Vout = −(2.5D2 + 1.25D1 + 0.625D0) V

For decimal code N = 4D2 + 2D1 + D0, the same result can be written as:

7. Simulation setup and observations

The uploaded screenshot appears to show a simulator schematic and a meter reading of approximately 0.420 mV. That reading alone does not establish the output for any particular code unless the digital input states and meter configuration are known. In an ideal circuit, code 000 should produce 0 V, while the other codes should follow the table above.

Verification procedure

  1. Confirm that R1, R2, R3 and R4 are 10 kΩ, 20 kΩ, 40 kΩ and 5 kΩ.
  2. Confirm that the op-amp's positive and negative supply pins are connected correctly to +12 V and −12 V.
  3. Ground the non-inverting input and verify that the feedback path returns from output to the inverting summing node.
  4. Apply input codes from 000 to 111 in order.
  5. Record the settled output for each code and compare it with the theoretical table.
  6. Investigate any mismatch by checking switch states, grounding, op-amp model, supply rails, and meter polarity.

8. Solved numerical examples

Example 1: Output for input 101

Given: D2 = 1, D1 = 0, D0 = 1.

Vout = −(2.5×1 + 1.25×0 + 0.625×1) = −3.125 V

Answer: −3.125 V ideally. The MSB and LSB contributions add at the summing node.

Example 2: Find the code for −3.75 V

Divide the output magnitude by the step size: 3.75/0.625 = 6. Decimal 6 is binary 110.

Answer: D2D1D0 = 110.

Example 3: Calculate output current at code 111

At code 111, the ideal summed current is 5/10 kΩ + 5/20 kΩ + 5/40 kΩ = 0.5 mA + 0.25 mA + 0.125 mA = 0.875 mA.

Vout = −Rf IΣ = −(5 kΩ)(0.875 mA) = −4.375 V

Answer: The feedback current magnitude is 0.875 mA and the ideal output is −4.375 V.

GATE-style shortcut

For this exact circuit, convert the binary code to decimal N and use Vout = −0.625N V. This shortcut is valid only while the stated logic level and resistor ratios remain unchanged.

10. Core electronics interview questions

1. What is a DAC?

A digital-to-analog converter converts a digital code into a proportional analog signal such as voltage or current.

2. Why is this circuit called a weighted-resistor DAC?

Each input resistor is scaled by a power of two, giving each bit a binary-scaled contribution to the summed current.

3. Why is the output negative?

The inputs feed the op-amp's inverting terminal. Negative feedback produces an output of opposite polarity to the summed input current.

4. What does the feedback resistor do?

It converts the summed input current into an output voltage and sets the current-to-voltage scale.

5. What is the LSB step in this circuit?

0.625 V in output magnitude, using a 5 V logic HIGH, a 40 kΩ LSB resistor and a 5 kΩ feedback resistor.

6. What happens if R3 is not exactly 40 kΩ?

The LSB contribution changes, causing gain error and possibly nonuniform step sizes. Large errors can affect monotonicity.

7. Why use ±12 V rails?

The output must swing below ground. A negative supply rail allows the op-amp to generate the required negative output, subject to its output-swing limits.

8. What is virtual ground?

With negative feedback and linear operation, the inverting input is held close to the grounded non-inverting input voltage, but is not physically connected to ground.

9. How would you troubleshoot an output stuck near zero?

Check that at least one input is HIGH, the input sources share the correct ground reference, the feedback resistor is connected, the op-amp supply pins are powered, and the meter is connected correctly.

10. What is a key limitation of a binary-weighted DAC?

It requires a wide range of accurate resistor values. For larger bit counts, matching the resistor ratios becomes difficult; an R–2R ladder is often preferred.

11. What does monotonic mean?

As the digital code increases, the output should move consistently in one direction. For this inverting DAC, the signed voltage becomes more negative with each increment.

12. How can you obtain a positive output?

Add a suitable unity-gain inverting stage after this circuit, or redesign the conversion stage to provide the required polarity while checking output range and loading.

Common mistakes

  • Swapping MSB and LSB resistor connections.
  • Forgetting the negative sign of the inverting summer.
  • Using Rf = 10 kΩ in calculations when the schematic shows 5 kΩ.
  • Assuming the displayed meter reading represents every input combination.
  • Forgetting the op-amp supply rails or a common ground reference.
  • Calling illustrative values measured results.

13. Applications, advantages and limitations

Applications

  • Generating programmable reference voltages.
  • Basic waveform generation and signal reconstruction demonstrations.
  • Control and instrumentation circuits that require analog setpoints.
  • Teaching binary weighting, current summation, and op-amp feedback.

Advantages

  • Simple to understand and calculate.
  • Direct relationship between bits and analog output.
  • Uses a small number of components for three bits.

Limitations

  • Needs accurately ratioed resistors.
  • Input loading and logic-source resistance can alter weighting.
  • Op-amp offset, bias current, finite gain, and output swing cause practical errors.
  • Scaling to many bits becomes inconvenient; R–2R ladder DACs are often more practical.
