1–2. Introduction

A square-wave generator (astable multivibrator / relaxation oscillator) is a Schmitt-trigger comparator whose input is fed by an RC network driven from its own output. It has no stable state: the output flips between +Vsat and −Vsat forever. Uses: clocks, PWM, timers, test signals.

Why oscillation: positive feedback (R1/R2) creates hysteresis thresholds ±βVsat; negative RC feedback makes the capacitor slowly chase the output until it crosses a threshold, then regeneration flips the output.

Prerequisites: comparator, Schmitt trigger, RC charging, positive vs negative feedback. Terms: Vsat (output saturation), UTP/LTP (upper/lower trip points, here +βVsat/−βVsat), hysteresis (UTP−LTP = 2βVsat), duty cycle (t_high/T), period T, frequency f=1/T, slew rate (max dVo/dt, V/µs).

Waveform-generator families: astable (this circuit, 555), monostable (one-shot), bistable (latch/Schmitt), 555 timer, Wien-bridge and phase-shift (sinusoidal, linear oscillators).

4. Working principle

  1. Initial state: noise/offset pushes Vo to, say, +Vsat. V+ = +βVsat. C charges through R toward +Vsat.
  2. Threshold crossing: when Vc reaches +βVsat, V− > V+, the differential input reverses; positive feedback regenerates and Vo snaps to −Vsat, so V+ = −βVsat.
  3. Discharge/reverse charge: C now discharges and charges toward −Vsat until Vc = −βVsat; Vo flips to +Vsat. Cycle repeats.
  4. Self-starting: an ideal 0 V balance is unstable; any noise or input offset triggers the first transition.

Waveforms: Vo = square wave ±Vsat; Vc = exponential segments between ±βVsat (rounded triangle-like); V+ = scaled square wave ±βVsat (it follows Vo, not Vc).

Assumptions: ideal op-amp, symmetric ±Vsat, infinite input impedance, negligible switching delay. Advantages: few parts, no inductors, simple tunable frequency. Limitations: slew rate slows edges and caps frequency; Vsat tolerance/supply affects amplitude (and period if Vsat is asymmetric); poor stability vs temperature; 741-class op-amps are slow.

Misconceptions: (1) the capacitor does NOT reach ±Vsat — it is clamped at ±βVsat; (2) the circuit is not negative-feedback only — positive feedback creates the thresholds; (3) T does not depend on Vsat if the saturation is symmetric.

Design notes: use rail-to-rail or fast op-amp for kHz+; keep R in 10 kΩ–1 MΩ; use stable (film/C0G) C; keep R1+R2 well above the load limit.

6. Equations and derivations

Thresholds: V+ = Vo·R2/(R1+R2) = βVo, so UTP = +βVsat, LTP = −βVsat (β dimensionless, 0<β<1).

Capacitor equation (charging toward Vo = Vsat from v0, τ = RC in s):

v_c(t) = Vsat − (Vsat − v0)·e^(−t/RC)

Half period: from v0 = −βVsat to +βVsat: βVsat = Vsat − (Vsat + βVsat)e^(−t1/RC) → e^(−t1/RC) = (1−β)/(1+β)

t1 = RC·ln[(1+β)/(1−β)]   T = 2t1 = 2RC·ln[(1+β)/(1−β)]   f = 1/T

Special cases: β = 0.5 (R1=R2): T = 2RC ln3 = 2.197RC ≈ 2.2RC. T = 2RC when (1+β)/(1−β) = e → β = (e−1)/(e+1) = 0.462 (R1/R2 ≈ 1.164, R2/R1 ≈ 0.86).

Limits: β→0: T ≈ 4βRC → 0 (thresholds collapse, rapid toggling, limited by op-amp speed). β→1: ln→∞, T→∞ (thresholds approach Vsat; the capacitor never reaches them).

Asymmetric saturation (+V₊, −V₋ magnitudes): UTP = βV₊, LTP = −βV₋; t_high = RC·ln[(V₊+βV₋)/(V₊(1−β))], t_low = RC·ln[(V₋+βV₊)/(V₋(1−β))]; duty = t_high/(t_high+t_low) ≠ 50 %.

Slew rate: the output edge takes ≈ 2Vsat/SR (e.g., 741: SR ≈ 0.5 V/µs → 24 V swing ≈ 48 µs); practical f_max is about 1/(20 × edge time) for a decent waveform (≈ 1 kHz-ish for a 741 at 24 V swing, a rule of thumb).

Meaning: T depends only on RC and β — not on Vsat for symmetric rails, since thresholds scale with Vsat.

7. Solved numerical problems

P1 (Easy): find f

Given R1=R2=10 kΩ, R=10 kΩ, C=0.1 µF. Required f. β = 10/20 = 0.5. T = 2·(10k·0.1µ)·ln3 = 2×1 ms×1.0986 = 2.197 ms; f = 455 Hz. Interpretation: ≈ 1/(2.2RC).

P2 (Moderate): design for 1 kHz, C = 0.01 µF

Choose β = 0.462 so T = 2RC. R = T/(2C) = 1 ms/(2×0.01 µF) = 50 kΩ. R1/R2 = (1−β)/β = 1.164 → R2 = 10 kΩ, R1 = 11.6 kΩ (check: β = 0.4630, ln(1.463/0.537) = 1.0025 → T = 1.0025 ms, f = 997.5 Hz). Interpretation: E-series tolerance gives ~0.3 % error; add a trimmer on R.

P3 (Difficult): asymmetric saturation

Given +Vsat = +13 V, −Vsat = −9 V, R1=R2 (β=0.5), RC = 10 kΩ×0.1 µF = 1 ms. UTP = +6.5 V, LTP = −4.5 V. t_high = RC ln[(13+4.5)/(13−6.5)] = ln(2.692) = 0.990 ms; t_low = RC ln[(6.5+9)/(−4.5+9)] = ln(3.444) = 1.237 ms. T = 2.227 ms, f = 449 Hz, duty = 44.5 %. Interpretation: unequal rails skew the duty cycle; a diode-steered R (two different charging resistances) is the standard way to set duty deliberately.

P4: compare with the Multisim circuit

Given R = 10 kΩ, C = 1 µF, R1(theory) = 12 kΩ, R2(theory) = 10 kΩ, Vsat ≈ 11.3 V. β = 0.4545; ln(32/12) = 0.9808; T = 2×10 ms×0.9808 = 19.6 ms, f = 51 Hz, thresholds ±5.14 V. Screenshot (rough) ≈ 30 ms. Interpretation: amplitude and duty match; period needs careful cursor measurement (see Section 5).

10. Applications and industry relevance

Clock sources, PWM generators, function generators, tone/alarm generators, test signals for switching regulators, microcontroller-free timing. Design challenges: frequency stability, R/C temperature drift, supply dependence of amplitude, slew rate, output loading, bench testing with proper probing. Limitations and assumptions

Screenshot is embedded; the graph measurements are rough visual estimates, not instrument readings. The Multisim op-amp is a virtual model, so Vsat (≈11.3 V) and edge behaviour are model-dependent. The simulator and numerical examples assume ideal symmetric saturation (except P3), no op-amp delay, and that R1 = top divider resistor and R2 = bottom per the master prompt.
